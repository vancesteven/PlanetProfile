# Globe textures

Equirectangular global mosaics used by Utilities/globe_view.py
(1024x512 JPEG, downsampled). All public domain (NASA/USGS):

- europa.jpg — USGS Astrogeology, Europa Voyager–Galileo SSI global
  mosaic (500 m), CKAN quicklook.
- callisto.jpg — USGS Astrogeology, Callisto Voyager–Galileo SSI global
  mosaic, CKAN quicklook.
- enceladus.jpg — NASA/JPL/SSI Cassini global color mosaic (PIA18435).
- titan.jpg — NASA/JPL/SSI Cassini ISS global map June 2015 (PIA19658),
  cropped to the map area.

Missing bodies (e.g. Ganymede) fall back to a shaded sphere; add
<body>.jpg here to enable the texture.
