Titan — Test 49: Andrade + Yao 2014, 4 km clathrate cap

Body template: PPTest49.py (PPTest48 with clathMaxThick_m = 4 km, nClath = 30). Driver: Test49_mcmc_andrade_yao2014_clathrate.py.

Purpose

Perturbation check of Test 48 (Path B). Tests sensitivity of the Path B result (~100% Ih heating) to clathrate cap thickness. PPTest48 inherits a 5 km clathrate cap; here it is reduced to 4 km.

Body / template

  • Titan analog. Same parameters as PPTest48 except clathrate cap = 4 km (was 5 km).
  • Yao 2014 spherical Ih convection.
