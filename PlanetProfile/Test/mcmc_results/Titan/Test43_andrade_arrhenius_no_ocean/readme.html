Titan — Test 43: Andrade + Arrhenius viscosity, no-ocean

Body template: PPTest43.py. Driver: Test43_mcmc_andrade_arrhenius_no_ocean.py.

Body / template

  • Same Titan analog as Test 41 (no-ocean, ice all-the-way-down).
  • R = 2574.73 km, M = 1.3452 × 1023 kg.

Model assumptions

  • Andrade rheology with temperature-dependent ice viscosity: 
    eta(T) = etaMelt · exp(Eact/R · (1/T − 1/Tmelt))
    evaluated at each radial point using cached T(r).
  • MCMC samples melting-point viscosity etaMelt per phase; activation energies and melting temperatures held fixed.
  • Eta cap = 1025 Pa·s to prevent overflow in cold regions.
