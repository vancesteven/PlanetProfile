Titan — Test 41: Andrade rheology, no-ocean

PlanetProfile MCMC inference using pocoMC. Body template: PPTest41.py. Driver: Test41_mcmc_andrade_no_ocean.py.

Body / template

  • Body: Titan analog (parent: Saturn)
  • R = 2574.73 km, M = 1.3452 × 1023 kg, Tsurf = 94 K, Psurf = 0.15 MPa
  • C/MR² = 0.343 ± 0.001 (closure target for PP)
  • Eccentricity = 0.0288, n = 4.56 × 10-6 rad/s
  • NO_OCEAN_EXCEPT_INNER_ICES = True (ice all the way down)

Model assumptions

  • Self-consistent PP interior held fixed during MCMC; only rheology parameters vary.
  • Andrade rheology applied to ices Ih, III, V, VI; silicate sampled separately.
  • HP ices share a single sampled viscosity (eta_HP).
  • Tidal Love numbers from TidalPy radial_solver; per-phase tidal heating from calc_radial_volumetric_tidal_heating_from_rs_solution.

Observational constraints

  • Re(k2) = 0.608 ± 0.048 (Petricca et al. 2025, Cassini radio science)
  • |Im(k2)| = 0.135 ± 0.035 (Petricca et al. 2025)

Gaussian likelihood on Re(k2) and |Im(k2)|.

Forward model

  1. PlanetProfile is run once at PPTest41 settings to extract a self-consistent radial profile (r, ρ, VP, GS, η, phase) on the ALMA grid.
  2. Per MCMC sample, complex shear modulus is computed via TidalPy's Andrade rheology with sampled (alpha, zeta) and per-phase viscosities.
  3. radial_solver integrates the elastic-viscoelastic equations to give k2; tidal heating is integrated radially per phase.

Inference settings

  • Sampler: pocoMC (preconditioned Monte Carlo)
  • Effective sample size target: 500
  • Random seed: 42
  • Posterior re-evaluations for heating/k2 plots: 500
