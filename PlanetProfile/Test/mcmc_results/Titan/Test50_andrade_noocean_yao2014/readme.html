Titan — Test 50: No-ocean + Andrade + Yao 2014

Body template: PPTest50.py. Driver: Test50_mcmc_andrade_noocean_yao2014.py. Default config: test50_titan_noocean_andrade_8D.json.

Hypothesis

Tests Petricca's hypothesis that no-ocean + coupled HP ices can supply Im(k2) via HP dissipation. Adds Yao 2014 spherical convection on top of PPTest46_allice base.

Body / template

  • Titan analog. R = 2574.73 km, M = 1.3452 × 1023 kg, Tsurf = 94 K.
  • HYDROSPHERE_THICKNESS = False; NO_OCEAN_EXCEPT_INNER_ICES = True.
  • SPHERICAL_CONVECTION = True (Yao 2014).
  • Clathrate cap: 2 km, nClath = 30.
  • KALOUSOVA_CONVECTION = True; ARRHENIUS_VISCOSITY = True; DO_SELF_CONSISTENT_HTIDAL = True.
  • Tb grid: 9 points linearly from 249.0 K to 250.965 K (just below Ih-III-L triple point).

Model assumptions

  • Andrade rheology with per-phase HP ice viscosities (III, V, VI sampled independently).
  • Arrhenius Ih: Eact = 60 kJ/mol; R = 8.314462 J/(mol·K).
  • Phase stability enforced: no_ocean_Ih with margin 0.1 K.
