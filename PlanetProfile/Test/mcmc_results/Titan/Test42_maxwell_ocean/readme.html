Titan — Test 42: Maxwell rheology, ocean-bearing

Body template: PPTest42.py. Driver: Test42_mcmc_maxwell_ocean.py.

Body / template

  • Titan analog with subsurface liquid water ocean.
  • R = 2574.73 km, M = 1.3452 × 1023 kg.
  • Structure varies with sampled basal temperature Tb.

Model assumptions

  • Maxwell rheology: ices and silicates (Fe = elastic, ocean = newton, clathrate top = elastic).
  • Structure pre-computed on a Tb grid: 251.2 → 275.0 K at 0.5 K spacing (48 points).
  • Nearest-neighbour structure lookup per MCMC sample for Tb; ice shell thickness, ocean depth follow from PP closure.

Observational constraints

  • Re(k2) = 0.608 ± 0.048 (Petricca et al. 2025)
  • |Im(k2)| = 0.135 ± 0.035 (Petricca et al. 2025)

Forward model

  1. One-time PP run for each Tb grid point; cache structural arrays in maxwell_ocean_structure_cache.pkl.
  2. Per MCMC sample, look up cached structure for sampled Tb, override viscosities per phase.
  3. TidalPy Maxwell rheology + radial_solver for k2; volumetric tidal heating per phase.

Inference settings

  • Sampler: pocoMC; n_eff target = 500; seed = 42; n_reeval = 500.
