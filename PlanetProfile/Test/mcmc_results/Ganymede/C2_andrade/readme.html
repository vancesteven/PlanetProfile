Ganymede — Phase C2 Andrade MCMC

Config: ganymede_pureh2o_andrade_8D.json. Driver: run_inference_cli.py.

Body / template

  • Ganymede with pure H2O ocean.
  • HP ice shell present (Ice III/V/VI locked together via param_groups).
  • R ≈ 2631 km; R_core upper bound = 1315.6 km = 0.5 R.

Model assumptions

  • Andrade rheology; HP ice viscosities locked (single log10_eta_HP for phases III, V, VI).
  • Mass conservation derives rho_sil ∈ [2200, 3500] kg/m³ (rejection sampled).
  • Arrhenius Ih: Eact = 60 kJ/mol; R = 8.314462 J/(mol·K).
  • Pure H2O ocean (no dissolved solutes).

Tb bounds rationale

Tb_K = [251.5, 267.5] K targets DiceIh ∈ [50, 149] km with Docean ∈ [12.3, 412] km. Lower 251.5 K just above TtripleIh-III-L = 251.165 K → Docean = 12.3 km. Upper 267.5 K → DiceIh ≈ 50 km. Probed via PlanetProfile.Inference.find_tb_bounds, 2026-05-23.
