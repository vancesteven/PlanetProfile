Europa — Phase C2 Andrade MCMC

Config: europa_seawater_andrade_7D.json. Driver: run_inference_cli.py. Phase C2 = Phase C1 observables expanded to include Re/Im(h2).

Body / template

  • Europa with seawater ocean (Constants.stdSeawater_ppt).
  • R = 1561 km. Ice shell is purely Ih (HP ices absent at this body size).
  • Phase C2 — observable expansion adds Re/Im(k2) and Re/Im(h2) (placeholders pending mission data).

Model assumptions

  • Andrade rheology; mass-conservation-derived rho_sil with rejection sampling.
  • Sampled core: R_core, rho_core; rho_sil derived to satisfy total mass with cached ice+ocean profile.
  • 7D problem (Ih only; no HP ice viscosity term).

Observational constraints

  • CMR² = 0.3547 ± 0.0024 (Gomez Casajus et al. 2021)
  • Re(k2) = 0.20 ± 0.05 (placeholder; Mazarico 2023)
  • Im(k2) = 0.0 ± 0.05
  • Re(h2) = 1.12 ± 0.10
  • Im(h2) = 0.0 ± 0.10
k2/h2 are placeholders. Update with Europa Clipper measurements when published. J2/C22 not used (no PP forward model for static gravity coefficients).

Inference settings

  • pocoMC; n_eff = 500; n_reeval = 500; seed = 42.
  • Structure cache: europa_seawater_structure_grid.pkl (shared with Test51_seawater/).
