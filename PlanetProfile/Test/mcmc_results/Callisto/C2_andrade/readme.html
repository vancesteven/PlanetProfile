Callisto — Phase C2 Andrade MCMC

Active config: callisto_nacl_andrade_8D.json. Deprecated config: callisto_mgso4_andrade_8D.json. Driver: run_inference_cli.py.

Body / template

  • Callisto with NaCl 100 ppt ocean (active config).
  • HP ice shell present (Ice III/V/VI locked together via param_groups).
  • R ≈ 2410 km; R_core upper bound = 1205.15 km = 0.5 R.

Model assumptions

  • Andrade rheology; HP ice viscosities locked (single log10_eta_HP applied to phases III, V, VI).
  • Mass conservation derives rho_sil ∈ [1800, 3500] kg/m³ (lower floor than Europa because Callisto silicate is porous; φ_vac ≈ 0.91 → ρ_sil ≈ 2025 kg/m³).
  • Ocean composition: NaCl 100 ppt — switched from MgSO4 because SeaFreeze NaCl extends to P = 5000 MPa (vs MgSO4 P < 800 MPa), avoiding slow extrapolation regeneration.
  • Arrhenius Ih: Eact = 60 kJ/mol; R = 8.314462 J/(mol·K).

Tb bounds rationale

Tb_K = [250.0, 254.9] K targets DiceIh ∈ [102, 140] km with Docean ∈ [10, 67] km. Cold bound 250.0 K is below pure-water Ih-III-L triple (251.165 K) but PP converges with NaCl 100 ppt (freezing-point depression). Warm bound 254.9 K → DiceIh ≈ 102 km. Probed via PlanetProfile.Inference.find_tb_bounds.
